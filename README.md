# 英雄立志传·三国志 存档修改器（Legend of Heros Save Editor）

## 快速开始

### 下载

到 [Releases](https://github.com/kinchan02/legendofheros-save-editor/releases) 下载最新版 `英雄立志传三国志-存档修改器Vx.y.z.exe`，双击运行即可（单文件，无需安装）。

### 修改存档

1. 启动修改器，点击「读取存档…」选择存档文件  
   （默认目录：`%USERPROFILE%\AppData\LocalLow\FreeWing\ThreeKingdom\SaveData\`）
2. 在各标签页里修改想要的数值
3. 点击「生成并保存新存档…」，**进游戏前建议先备份原档**（修改器自带「备份存档…」按钮）

> ⚠️ 修改存档有风险，请务必备份原档。若游戏更新后存档结构变化，请等修改器适配后再修改。

## 从源码运行

```bash
git clone https://github.com/kinchan02/legendofheros-save-editor.git
cd legendofheros-save-editor
python App/三国存档修改器.py
```

依赖：Python 3.8+（标准库即可运行，Pillow 可选增强图标显示）。
